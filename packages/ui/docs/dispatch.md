## Dispatch Control Panel

- Location: src/views/dispatch/index.jsx
- Sidebar: menu-items/dashboard.js -> Dispatch menu item
- Dashboard: Shows Nodes, Slots usage, and Task queue
- Auto-refresh: every 10 seconds (REFRESH_INTERVAL_MS)
- API: /api/v1/dispatch/\* (Nodes, Slots, Tasks)

How to use:

- Open the UI and click Dispatch in the left sidebar
- View cluster status and counts
